# 验证记录与已知限制

## 本次发布检查

- 固件 2.2.0 由仓库内源码完成编译，RAM 47036 字节，Flash 1353712 字节（约 43% 应用分区）。
- Windows 接收器完成本机编译与解析自检：UTF-8 中文、转义字符、表情代理对、非法输入拒绝、Windows 换行转换。
- EXE 为 PE32 x86，系统/子系统版本 5.1，仅使用 Windows 系统 DLL，不依赖 VC 运行库。
- 本地 UI 夹具验证手机页面输入与保存、配置页 Wi-Fi 列表和模型测试反馈、局域网页面接收中文/多行/表情及确认请求。`<script>` 示例按普通文字显示。
- 文档截图只包含合成数据；没有真实 Token、个人消息、实际 Wi-Fi 名称或设备备份。
- 发布包提供 SHA-256；APK 与 EXE 的嵌入数组和待发布文件逐字节核对。

## 此前在实际 ESP32-C3 上完成

固件 2.0 / 2.1 曾验证：BLE 发现和加密配对、UTF-8 分包、原文 BLE → USB、正确/错误 ACK、错误管理密码拒绝、模型参数校验及 Token 不回显；板内模拟 Chat Completions 的成功与 HTTP 401；实际 Wi-Fi 扫描；模型测试不进入 PC 队列；LittleFS 测试记录复位后保持一致。

这些是旧版本的硬件测试结果，不代表新增 2.2 网络接收路径已经在板子上验证。`ai-bridge/tools/verify_ble.py` 和 `verify_upgrade.py` 保留版本断言，分别对应历史 2.0 / 2.1，不作为 2.2 自动回归命令。前者会修改/清除测试板模型配置，只能用于可重置的测试设备。

## 使用时注意

原文通过 USB 转发不需要 Wi-Fi 或互联网；局域网接收需要电脑能够通过本地网络访问板子；远程模型处理需要板子能访问模型服务。

该板的 USB 提供串口，不能直接变成通用 USB 键盘。本项目不会自动向任意软件输入文字。当前版本处理纯文字，未实现录音、语音识别或音频上传。
